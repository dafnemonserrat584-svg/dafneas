1. Desarrollo Web: HTML

Ejemplos prácticos de las etiquetas y atributos vistos en clase, mostrando su sintaxis y su resultado visual.

Title (Título de la pestaña)

Sirve para ponerle un título a la página web. Se coloca dentro de la etiqueta <head>.

<title>Programación 606</title>

Html (Estructura principal)

Es todo lo que pasa el código, el contenedor raíz de la página.

<html>
   ... todo el código ...
</html>

Body (Cuerpo visible)

Es todo el contenido visible de la página web.

<body>
   ... contenido visible ...
</body>

H1 (Título principal)

<h1>Título de la página</h1>

Título de la página

P (Párrafo)

<p>Este es un párrafo de ejemplo</p>

Este es un párrafo de ejemplo

Marquee (Texto en movimiento)

Para que gire el texto de derecha a izquierda o inversa (etiqueta clásica).

<marquee direction="right" speed="5" behavior="alternate">
   Texto que gira
</marquee>
Texto que gira

Body bgcolor (Fondo de color)

Se utiliza para ponerle fondo de un color a la página (atributo clásico).

<body bgcolor="#fce4ec">

Nota: src Este atributo se aplica directamente a la etiqueta <body>. Aquí vemos un ejemplo de fondo rosa claro.

A href (Vínculos / Enlaces)

Se mete al link al darle clic. En este ejemplo, el texto es de color rosa.

<a href="https://www.youtube.com" style="color: deeppink;">Ir a YouTube</a>
Ir a YouTube (Rosa)

P style (Estilos en línea)

Le agrega color a la letra y tamaño.

<p style="color: #e91e63; font-size: 24px;">Texto con estilo</p>

Texto con estilo
